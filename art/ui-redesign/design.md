# UI direction

Created with the built-in ImageGen tool. `mockups.png` is the design sheet created before implementation.

The implementation uses Newsreader headings and DM Sans body text, ivory menus (#F3F0E8), charcoal text (#232622), olive accents (#737A64), quiet dividers, and a separate dark gameplay HUD. It preserves the actual player model, arena, and available settings; the generated concept's extra volume sliders and alternate arena are not new features.

## Generation prompt

Use case: ui-mockup. Create a precise high-fidelity design sheet with FOUR game UI screen mockups arranged in a clean 2x2 grid. This is a practical redesign for an existing indie top-down rat survival game called Project R.A.T. Flat front-on screens, no device frames, no perspective. Each screen 16:9. Large overall canvas, sharp highly legible typography.
Visual direction: quiet refined editorial design, warm ivory #F3F0E8 menu backgrounds, very dark charcoal #232622 text, muted olive #737A64 accent, thin pale #D9D9CE rules. A graceful medium-weight serif for titles (like Newsreader), a clean humanist sans for controls (like DM Sans). Generous margins, good alignment. No uppercase marketing slogans, no enormous condensed text, no gradients, no glow, no ornamental badges, no SaaS dashboard aesthetic.
TOP LEFT title screen: left 40% has small understated Project R.A.T. wordmark in header, large serif title 'Project R.A.T.' broken naturally over two lines at center-left, a short line 'A little rat. A very long night.' beneath in quiet small sans, one charcoal rectangular 'Start run' button 240x52 with subtly rounded corners, and a simple text-only 'Settings' option below. Right half showcases a small stylized 3D grey rat with big pink ears, red neckerchief, blue jacket, and seed blaster, matching the existing game's player, full body, standing on subtle oval shadow. The character is isolated on the same ivory ground. NO forest, eclipse, extra monster or invented scenery. Thin bottom divider and small keyboard controls 'WASD Move     Mouse Aim     Shift Dash'. Lots of whitespace. Rat should fill about one third of height.
TOP RIGHT settings: same ivory paper, top left serif 'Settings', subtitle 'Make yourself comfortable.' Header right simple 'Done' text button. Two evenly spaced columns 'Sound & comfort' and 'Keyboard'. The left has restrained horizontal rows for Volume and Camera shake sliders with numeric percent; toggles for Aim assist, Easy mode, Large text, Hints. The right has label/key pairs like Move up W, Move left A, Move down S, Move right D, Aim Arrow keys, Dash Shift, Auto-fire F, Pause Esc. Thin row rules rather than boxes. Clear charcoal on ivory, olive active toggles, no heavy card borders.
BOTTOM LEFT upgrade: ivory full screen with small 'Wave clear' eyebrow; large serif 'Choose an upgrade' left aligned. Small 'Your choice lasts for the rest of this run.' Three equally spaced horizontal option columns separated only by thin vertical rules. Each has one small olive simple line icon, title in medium sans: 'Bounce', 'Dash bomb', 'Orbit'; plain descriptions 'Bullets bounce off walls once.', 'Dashing leaves an explosive crumb.', 'Three orbiting seeds. Pickups recharge them.' Footer on each small 'Choose [1]' etc. First option very subtle tinted background and fine olive focus edge. No large numbered badge, no top card kicker.
BOTTOM RIGHT gameplay HUD: clearly separate dark actual gameplay arena with little grey rat at center and a few stylized enemies, top-down view. UI must stay out of play: top left compact 'Wave 07' then small 'Ranged siege', thin wave meter beneath; top right score '12,450' with small 'Score', beneath '24 kills · x3 streak'. Bottom left one discreet translucent charcoal compact strip containing Health 84/100 with warm ivory meter and Dash Ready [Shift] with short olive meter. Bottom right a quiet 'Auto-fire On [F]' and 'Esc Pause'. No large boxes or outlines, no decorative UI framing.
The four screens should look like one professionally authored game interface. The mockups must be realistically implementable in Godot with live controls.
